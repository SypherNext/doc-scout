# Step 001: Course Overview

This is the first course in a four-course path that takes you from your first Python script to a production AI service. It teaches the language itself, from the setup (Python 3.12 or 3.13, a virtual environment per project) through the core types (strings, lists, tuples, dictionaries and sets) to control flow, loops, functions, modules, file handling and comprehensions. Each topic has a hands-on lesson and a review,...

This lesson is conceptual (an overview or a review) and introduces no new runnable scripts of its own; see the Hands-On and Common Mistakes steps around it for code.
