# Step 002: Setting Up Python for AI Engineering

Every AI engineering workflow starts with a working Python installation. You will install libraries like `numpy`, `transformers`, `openai`, and `langchain`, run training scripts, launch Jupyter notebooks, and deploy inference servers.
